# Proyecto SkyTrack

**Estudiante:** Lautaro Enrique Kruck Ponce  
**Curso:** 2º Desarrollo de Aplicaciones Web (DAW)

## 1. Introducción

Este proyecto consiste en el diseño de una interfaz de usuario para una aplicación web de comparación de vuelos, llamada SkyTrack. Utilizando Figma, se ha creado una guía visual que incluye los aspectos clave de diseño, como la paleta de colores, tipografía y componentes de interfaz. Este diseño será la base para la maquetación en el módulo de Desarrollo Web en Entorno Cliente.

## 2. Paleta de Colores

Se ha elegido una paleta de colores que inspira confianza y profesionalismo, elementos importantes para una aplicación de viajes. La paleta consta de:

**Colores Primarios:**
- **Azul Marino (#003366):** Transmite estabilidad y seguridad.
- **Celeste (#1E90FF):** Aporta frescura y modernidad al diseño.
- **Blanco (#FFFFFF):** Para contrastes y mantener una apariencia limpia.

**Colores Secundarios:**
- **Gris Oscuro (#4F4F4F):** Para el texto y elementos de menor importancia.
- **Gris Claro (#E0E0E0):** Utilizado en botones deshabilitados y campos de formulario.

## 3. Tipografía

Se ha elegido la tipografía **Roboto** (disponible en Google Fonts) por su claridad y adaptabilidad en entornos digitales.

- **h1:** 28px, Negrita (para títulos de página)
- **h2:** 22px, Semi-Negrita (para subtítulos)
- **h3:** 18px, Regular (para subtítulos menores)
- **Texto de párrafo:** 16px, Regular
- **Texto secundario:** 14px, Regular, color gris oscuro

## 4. Componentes de UI

**Botones:**
- **Botón Primario:** Color celeste (#1E90FF), con texto blanco para mejor visibilidad.
- **Estado Normal:** Fondo celeste.
- **Hover:** Tono más oscuro (#003366) para indicar interacción.
- **Deshabilitado:** Fondo gris claro (#E0E0E0), texto gris oscuro (#4F4F4F).

**Campos de Formularios:**
- **Bordes:** Azul marino (#003366), lo que crea un marco distintivo.
- **Texto de marcador de posición:** Celeste (#1E90FF), ayudando a guiar al usuario.
- **Texto de entrada:** Negro (#000000), para alta legibilidad.

## 5. Estructura de Páginas

- **Página de Inicio:** Contiene el buscador de vuelos y secciones destacadas para promociones y ofertas de última hora. Incluye también navegación rápida y acceso a redes sociales.
- **Página de Login y Registro:** Formularios para acceder o crear una cuenta. Incluye validaciones y una apariencia uniforme con el resto del sitio.
- **Perfil de Usuario:** Permite al usuario editar información personal y ver detalles de su cuenta.
- **Formulario de Contacto:** Una página para que los usuarios envíen mensajes o consultas.
- **Página 404:** Muestra un mensaje amigable cuando no se encuentra la página solicitada.

## 6. Justificación de Diseño

- **Colores:** Se ha buscado una paleta amigable y profesional. El azul representa confianza y es un color común en aplicaciones de viajes.
- **Tipografía:** La elección de fuentes claras y modernas facilita la lectura en todos los dispositivos.
- **Interfaz Consistente:** Se ha mantenido un diseño coherente entre todas las páginas, facilitando la navegación del usuario.
- **Accesibilidad:** Se han tenido en cuenta principios básicos de accesibilidad, como el contraste entre texto y fondo, para asegurar una experiencia inclusiva.
